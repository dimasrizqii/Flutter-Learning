## Final Project - ShopApp

> **Aplikasi E-Commerce lengkap dengan Clean Architecture, BLoC Pattern, dan Firebase Integration**

Proyek akhir bootcamp berupa aplikasi e-commerce mobile yang memungkinkan pengguna untuk browsing produk, mengelola keranjang belanja, dan autentikasi pengguna.

**Fitur Utama:**

- Autentikasi dengan Firebase (Login/Register)
- Katalog produk dengan filter kategori
- Keranjang belanja dengan Firestore real-time sync
- Clean Architecture & BLoC State Management
- Material Design 3 & Responsive UI

**Tech Stack:** Flutter, Firebase Auth, Cloud Firestore, BLoC, GoRouter, REST API

[Lihat Dokumentasi Lengkap](Final%20Project/final_project/README.md)
