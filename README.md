# BootcampFlutter

Repository ini berisi kumpulan tugas-tugas dari Bootcamp Flutter Sanbercode.

## Author

Repository Bootcamp Flutter - Sanbercode

## Daftar Tugas

### Tugas 1 - Git

Pengenalan dan praktik penggunaan Git untuk version control.

### Tugas 2 - Intro Dart & Conditional

Materi pengenalan bahasa pemrograman Dart dan struktur kontrol conditional.

- **Tugas 2A - Type Data**: Mempelajari tipe data di Dart ([type.dart](Tugas-2-Intro%20Dart%20&%20Conditional/Tugas-2A-TypeData/type.dart))
- **Tugas 2B - Conditional**: Implementasi struktur kontrol conditional (if-else, switch-case) ([conditional.dart](Tugas-2-Intro%20Dart%20&%20Conditional/Tugas-2B-Conditional/conditional.dart))

### Tugas 3 - Looping dan Function

Mempelajari perulangan (looping) dan fungsi (function) dalam Dart.

- **Tugas 3A - Looping**: Implementasi berbagai jenis perulangan (for, while, do-while) ([looping.dart](Tugas-3-Looping%20dan%20Function/Tugas-3A-Looping/looping.dart))
- **Tugas 3B - Function**: Membuat dan menggunakan fungsi di Dart ([function.dart])

## Cara Menjalankan

Pastikan Anda sudah menginstall Dart SDK. Untuk menjalankan file Dart:

```bash
dart run <nama_file.dart>
```

Contoh:
```bash
dart run "Tugas-2-Intro Dart & Conditional/Tugas-2A-TypeData/type.dart"
```
