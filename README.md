# BootcampFlutter

Repository ini berisi kumpulan tugas-tugas dari Bootcamp Flutter Sanbercode.

## Author

Repository Bootcamp Flutter - Sanbercode

## Daftar Tugas

### Tugas 1 - Git

Pengenalan dan praktik penggunaan Git untuk version control.

### Tugas 2 - Intro Dart & Conditional

Materi pengenalan bahasa pemrograman Dart dan struktur kontrol conditional.

- **Tugas 2A - Type Data**: Mempelajari tipe data di Dart ([type.dart](Tugas-2-Intro%20Dart%20&%20Conditional/Tugas-2A-TypeData/type.dart))
- **Tugas 2B - Conditional**: Implementasi struktur kontrol conditional (if-else, switch-case) ([conditional.dart](Tugas-2-Intro%20Dart%20&%20Conditional/Tugas-2B-Conditional/conditional.dart))

### Tugas 3 - Looping dan Function

Mempelajari perulangan (looping) dan fungsi (function) dalam Dart.

- **Tugas 3A - Looping**: Implementasi berbagai jenis perulangan (for, while, do-while) ([looping.dart](Tugas-3-Looping%20dan%20Function/Tugas-3A-Looping/looping.dart))
- **Tugas 3B - Function**: Membuat dan menggunakan fungsi di Dart ([function.dart](Tugas-3-Looping%20dan%20Function/Tugas-3B-Function/function.dart))

### Tugas 4 - List dan Map

Mempelajari struktur data List dan Map dalam Dart.

- **Soal 1**: Range ([soal1.dart](Tugas-4-List%20dan%20Map/soal1.dart))
- **Soal 2**: Range With Step ([soal2.dart](Tugas-4-List%20dan%20Map/soal2.dart))
- **Soal 3**: List Multidimensi ([soal3.dart](Tugas-4-List%20dan%20Map/soal3.dart))

### Tugas 5 - OOP

Mempelajari konsep Object-Oriented Programming (OOP) dalam Dart.

- **Soal 1 - Prosedural ke Class**: Konversi dari paradigma prosedural ke OOP ([Segitiga.dart](Tugas-5-OOP/soal1-prosedural-ke-class/Segitiga.dart), [soal1.dart](Tugas-5-OOP/soal1-prosedural-ke-class/soal1.dart))
- **Soal 2 - Enkapsulasi**: Implementasi enkapsulasi dengan getter dan setter ([Lingkaran.dart](Tugas-5-OOP/soal2-enkapsulasi/Lingkaran.dart), [soal2.dart](Tugas-5-OOP/soal2-enkapsulasi/soal2.dart))
- **Soal 3 - Inheritance**: Implementasi inheritance dengan tema Attack on Titan ([main.dart](Tugas-5-OOP/soal3-inheritance/main.dart))
  - [human.dart](Tugas-5-OOP/soal3-inheritance/human.dart)
  - [titan.dart](Tugas-5-OOP/soal3-inheritance/titan.dart)
  - [attack_titan.dart](Tugas-5-OOP/soal3-inheritance/attack_titan.dart)
  - [armor_titan.dart](Tugas-5-OOP/soal3-inheritance/armor_titan.dart)
  - [beast_titan.dart](Tugas-5-OOP/soal3-inheritance/beast_titan.dart)

### Tugas 6 - Async Await Future

Mempelajari pemrograman asynchronous dengan Async, Await, dan Future dalam Dart.

- **Soal 1**: Implementasi async-await ([soal1.dart](Tugas-6-AsyncAwaitFuture/soal1.dart))
- **Soal 2**: Penggunaan Future ([soal2.dart](Tugas-6-AsyncAwaitFuture/soal2.dart))
- **Soal 3**: Kombinasi async-await dan Future ([soal3.dart](Tugas-6-AsyncAwaitFuture/soal3.dart))
